# 标题后排版与歌词卡

## 标题流程

原图保留版先保护人物和大物体的布局，标题只能放现有背景空位；不得为了顶部居中或无字留白移动主体、彗星或地平线。其他版本再采用下述常规标题区。

先固定逐字文字清单。新增作者行未指定时使用字面 `Music by YOUR NAME`，不猜真实姓名，不抄案例作者行。英文主标题、副标题都须为Fraktur，不只让主标题用哥特字。原图中看清的中日文可以单独保留，避免和新增标题重叠；无字模式移除全部文字但不重排主体。

1. 优先让内置生图工具完成小标题，逐字查看结果。定向修字时锁定构图、人物、纸边与配色。
2. 单个错字或作者串名先仅做文字编辑，并锁住画面。稳定失败时生成完全无字底图，利用原有背景空位；海面也可作为标题区，不强加天空，不在乱码上叠加新字。
3. 检查本地字体，使用真实字体文件：英文主副标题选 UnifrakturMaguntia、UnifrakturCook、Old English Text 等Fraktur；作者行选细无衬线。中文选支持汉字的细宋体/明朝体，并保留英文哥特副标题。不能把普通衬线字体标作哥特。
4. 可用 `scripts/typeset_cover.py`（Pillow）给无字底图排字：

```bash
python <skill_dir>/scripts/typeset_cover.py \
  --image <clean-cover.png> --output <cover-titled.png> \
  --title 'The Last Wall' --subtitle 'Original Soundtrack' --author 'YOUR NAME' \
  --blackletter-font <actual-fraktur-font.ttf> --sans-font <actual-sans-font.ttf>
```

脚本依赖Pillow与fontTools，要求显式字体路径，不下载字体、不伪装字体、不覆盖原图，并在排版前检查字形覆盖。中文主标题用 `--title-font <Chinese-Ming-Song-font>` 单独指定中文字体，`--blackletter-font` 继续用于英文副标题；有中文作者名时作者字体也须支持汉字。无合适字体时，若生图工具可用，继续定向文字编辑，不必为可选排版中断整个任务。

两个脚本都支持 `--subtitle ''` 省略副标题，及 `--credit-text` 指定完整作者行（如裸署名 `LIN`）；空作者行用 `--credit-text ''`，不能额外补上Music by。用户只允许某几行文字时，严格使用该清单，不添加默认副标题。

排版目标：作者行字高约画面高度1%–1.5%，主标题2.3%–3.3%，副标题1.8%–2.6%；标题组距顶部约9%–25%内居中。长标题缩字号，不改字、不截断、不扩成大字。浅天空可加极细暗边，禁止粗发光或沉重底条。这些数值不代替实际视觉判断。

## 歌词卡

- 默认4:5整卡，如1600×2000；纯白到浅灰背景。
- 方形封面放在上部约70%高度区域。例如左右各留6%宽度、顶部4%，封面宽88%、高占整卡70.4%。这里70%指版面区域，不能强行拉伸正方形。
- 下部留足空白，左对齐两组“英文一行 / 中文翻译一行”，细体黑灰字。末行小字号灰色 `—— {歌名} • {歌手}`，稍缩进。
- 保留原歌词与用户译文，未给译文时可翻译。未给歌词时不能编造并署名真实歌曲；使用明确标注的原创短句，或只问实际缺失的歌词。
- 长句按行宽换行，不能压成小到看不清的字。放不下时减少歌词组数或按要求扩大画布，不挤压封面。
- 双联先完成两张独立卡，再等宽并排并留分隔白边。两卡各有自己的封面、歌词、署名，情绪可一问一答；不将不同歌曲句子混在一个署名下。
- 哥特标题留在封面内，歌词用普通细体，不把歌词排成整片哥特字。

查看整卡和100%局部：逐字正确、字形完整、清晰、无残留乱码、封面无拉伸、歌词署名对应。按当前文件保存机制保存后排版文件，用户需要时提供文件。
